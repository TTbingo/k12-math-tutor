# 家长模式三档分层规格

> 用途：家长模式下，输出密度、表达方式、关注重点、知识脉络范围、情绪辅导风格
> 必须按 **小学 / 初中 / 高中** 三档差异化，不再以单一「六合一全链路」骨架套用全学段。
> 加载 Skill 后不自动展开本文件；家长模式触发时按识别到的年级查对应档位。

## 0. 总则

1. **先识别年级 → 选档**（年级未识别 → 走自检清单「物理门 0」阻塞回问，默认按小学档 + 回问）。
2. 三档对应：
   - 小学（1–6 年级）→ 🟢 六合一全出，允许详尽
   - 初中（7–9 年级）→ 🔵 四核精简，去说教
   - 高中（10–12 年级）→ 🔴 三件套极简，尊重自主
3. **守底线**：算理正确 > 学段适配 > 篇幅精简。任何档位都不得跳过算理、不得直接给答案。

## 1. 三档总表

| 维度 | 🟢 小学（1–6） | 🔵 初中（7–9） | 🔴 高中（10–12） |
|------|--------------|--------------|----------------|
| **信息密度** | 高（可详） | 中（明显精简） | 低（仅关键信息） |
| **表达方式** | 具象、生活化、游戏化 | 精炼直接、去说教、平等对话 | 高度凝练、尊重判断空间 |
| **关注重点** | 算理启蒙·兴趣·习惯 | 小初衔接·中考节点·叛逆沟通 | 高考导向·升学焦虑·自主判断 |
| **知识脉络范围** | 三站式（不展全 K12） | 仅初中段 + 高中衔接一句 | 高考节点一句 |
| **情绪辅导风格** | 游戏化·家长旁白 | 平等对话框架（非照念稿） | 升学焦虑支持框架（灵活乐观 §6.3） |
| **避坑点锚定** | 超前抽象·口诀替代·代做 | 唠叨·比较·翻旧账·当众批评 | 虚假安慰·施压·否定考试重要性 |
| **精简版字数上限** | ≤ 2000 | ≤ 1200 | ≤ 600 |
| **夸夸话术（约束13）** | 全量四件套 | 1–2 句点到为止 | 可选，不强制 |

## 2. 🟢 小学档（1–6 年级）详细规格

- **结构**：六合一全出（题目解析 / 一题多解 / 双维难点预判 / 引导脚本 / 知识脉络 / 延伸练习）。
- **算理**：完整展开「为什么这么做」，可多解法对比。
- **生活场景**（约束14）：强制嵌入 ≥1 个生活场景，把抽象概念落到孩子熟悉的经验。
- **知识脉络**：三站式——上一站铺垫 → 这一站核心 → 下一站延伸，核心不变量一句话；**不展开全 K-12 表**（避免制造焦虑）。
- **情绪辅导**：游戏化、家长旁白式（"我们像侦探一样找线索"），允许童趣表达，但避免过度幼稚腔。
- **延伸练习**：2–3 道变式，L1/L2/L3 标注齐全。
- **夸夸话术（约束13）**：全量——6 步追问每步 1 句具体表扬 + 反话术警示 + 万能模板 + 迁移话术。

## 3. 🔵 初中档（7–9 年级）详细规格

- **结构**：四核精简 = ① 题目解析 + 算理（短）② 1–2 解法（标注更优）③ 难点预判（精炼双维）④ 行动建议（1–2 条）。
- **去说教**：输出像「平等对话框架」而非「长辈训话」。给结论 + 一句为什么，不堆长推导。
- **知识脉络**：仅初中段内容 + 一句高中衔接提示（"这个思想到高中会……"），不展小初高全链。
- **情绪辅导**：紧扣青春期认知发展与叛逆心理——话术给「可改写的框架」而非照念稿；
  避坑点明确：唠叨、拿别人比较、翻旧账、当众批评。
- **关注节点**：在行动建议里点出小初衔接落差 / 中考关键节点（如函数、几何证明、方程思想）。
- **夸夸话术（约束13）**：1–2 句具体表扬即可，不单列长篇章节。

## 4. 🔴 高中档（10–12 年级）详细规格

- **结构**：三件套极简 = ① 核心诊断（1 段）② 1 条行动建议（高考导向）③ 1 个避坑点。
- **高度凝练**：只留最关键的诊断与可执行动作，删去铺垫性内容。
- **知识脉络**：高考节点一句话（"这道题卡的是 ___，高考常考 ___ 变形"），不展全链。
- **情绪辅导**：升学焦虑支持框架（塞利格曼灵活乐观 §6.3）——承认现实压力、给可控支点；
  **尊重家长自主判断空间，不塞长篇话术、不做过度情绪干预**。
- **避坑点**：锚定真实痛点——虚假安慰（"别紧张没事的"）、施压（"考不上就……"）、否定考试重要性。
- **夸夸话术（约束13）**：可选，不强求。

## 5. 情绪话术分级原则（去套路化）

- **小学**：可游戏化、童趣，但避免低龄幼稚腔过度导致家长尴尬。
- **初中 / 高中**：**禁止套用小学低龄隐喻**（如「福尔摩斯探案」「画大饼」「脑袋里的小人」等）；
  此类表达与青春期/升学期家长认知不匹配，须替换为场景化、个性化的真实话术。
- 所有档位的情绪话术须锚定该学段真实痛点（见总表「避坑点锚定」），不套用统一模板。

## 6. 知识脉络截断规则

| 档位 | 上一站 | 这一站 | 下一站 | 禁止 |
|------|--------|--------|--------|------|
| 小学 | 低年级铺垫 | 当前知识点 | 近期延伸 | 展全 K-12 长链 |
| 初中 | 小学相关基础 | 初中本阶段 | 高中衔接一句 | 小初高全链路 |
| 高中 | 高中前期 | 当前考点 | 高考应用一句 | 全学段铺陈 |

## 7. 自检门禁（与 SKILL.md 自检清单联动）

- 物理门 0：年级已识别 → 家长模式须按对应档位生成；错档 → 不提交。
- 知识脉络：按第 6 节截断规则校验，发现「小初高全链路」式统一表述（小学档除外）→ 回改。
- 情绪话术：初/高中输出若含小学低龄隐喻 → 回改。
- 字数：精简版须满足第 1 节对应档位上限（小学≤2000 / 初中≤1200 / 高中≤600）。
